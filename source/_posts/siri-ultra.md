# Siri Ultra

> 运行在 Workers 上、兼容任意 LLM 的 Siri 助手

**仓库地址**：https://github.com/fatwang2/siri-ultra

## 项目简介

运行在 Workers 上、兼容任意 LLM 的 Siri 助手。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- Siri
- LLM
- Workers
