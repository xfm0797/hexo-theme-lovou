# CloudPaste

> 文本 / 大文件分享平台，支持 Markdown 渲染、阅后即焚、多存储聚合

**仓库地址**：https://github.com/ling-drag0n/CloudPaste

## 项目简介

文本 / 大文件分享平台，支持 Markdown 渲染、阅后即焚、多存储聚合。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- Pastebin
- Markdown
- 阅后即焚
- 多存储
