# serverless-cloud-notepad

> 基于 Worker 的云笔记

**仓库地址**：https://github.com/s0urcelab/serverless-cloud-notepad

## 项目简介

基于 Worker 的云笔记。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
