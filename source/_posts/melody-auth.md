# melody-auth

> Workers + D1 + KV 的 OAuth 及身份认证系统

**仓库地址**：https://github.com/ValueMelody/melody-auth

## 项目简介

Workers + D1 + KV 的 OAuth 及身份认证系统。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- OAuth
- 认证
- D1
- KV
