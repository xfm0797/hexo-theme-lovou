## 它想解决什么问题

智能电视的开机广告、厂商遥测、内容推荐行和一堆预装垃圾，是所有 Android TV 用户的共同痛点。传统解法要么 Root（风险高、保修作废），要么刷第三方固件（型号适配地狱）。

这个项目的起点很有时代特征：10 月 17 日，作者 Gathin 发了一条推文——父母家的电视被 Claude Code 通过 Wi-Fi 清理前后的对比，740 万阅读。随后四天里，回复汇成了 170+ 电视型号、200+ 贡献者的兼容列表。

## 核心机制拆解

**1. 只用 ADB，不动根。** Android TV 和安卓手机共享同一套调试桥，流程只有三步：

- **Back up**：导出已安装包列表和设置；
- **Disable**：用 `pm disable-user` 禁用厂商遥测、广告服务、内容推荐行和预装垃圾——**什么都不卸载**，所以一条还原脚本就能撤销全部操作；
- **Install**：装上 517KB 的原生启动器，设为默认桌面。

不 Root、不插线、不卸载、一行还原——这四条组合起来，才是它敢让普通人对自己电视动手的底气。

**2. 让 Agent 干脏活。** 电视端只需在开发者选项里打开 USB 调试（有 Network/ADB 调试开关也打开），电脑和电视连同一 Wi-Fi，然后把 `PROMPT.md` 贴进 Claude Code / Codex / Gemini CLI：助手会自己发现这台电视上的臃肿软件，动手前还会先问你哪些 App 要留。

**3. 社区驱动的兼容矩阵。** 33K Star 背后是 170+ 型号的实测清单——这类项目最大的难点从来不是技术，而是"我这款电视行不行"，而它用众包解决了。

## 安装与上手

- 项目仓库：<https://github.com/Gathin23/cleanyourtv>
- 前置：电视开启 ADB 调试，与电脑同一局域网
- 用法：把仓库里的 PROMPT.md 交给任意 CLI Agent，按提示确认要保留的应用

## 点评

**亮点**是"可逆"这个设计前提。禁用而不卸载，意味着任何一个普通用户都敢试——把不可逆的系统改造变成一次可回滚的配置调整，这是它能爆红的产品原因。

**局限**也要说清：ADB 调试本身对非技术用户有门槛；不同厂商 ROM 的包名差异大，社区清单之外的型号需要自己排查；禁用某些厂商组件可能影响系统更新或语音助手等联动功能。

适合人群：受够开机广告与推荐行的 Android TV / Google TV 用户；愿意花十分钟换一个干净桌面的极客；想看看"Agent 直接操作真实设备"能落地的普通用户。
