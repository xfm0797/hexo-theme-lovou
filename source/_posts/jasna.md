## 它想解决什么问题

视频马赛克还原是视频修复里最"硬"的一类任务：马赛克区域信息已被有损压缩摧毁，需要**时序超分 + 生成式补全**双管齐下，而且必须逐帧跟踪马赛克位置、按片段（clip）做时序一致的修复，再无缝合成回原画面。Jasna 把这条流水线做成了开箱即用的桌面应用：**只还原你选定的马赛克区域，画面其余部分一个像素不动**，支持 VR180 视频与静图，全流程在本地 GPU 上完成。

## 核心机制拆解

**1. 七步 GPU 流水线。** 从读视频到存结果几乎全在 GPU 上：

**2. 双模型路线。** 免费档 **BasicVSR++** 快但细节有限；赞助者档 **LTX** 走扩散模型四阶段流程（找马赛克 → 准备 → 扩散还原 → 保存），慢得多但能补出更多真实细节，仅支持 NVIDIA。另有 UNet 4x（$15+ 赞助）与 SD 1.5 静图实验模型（$25+ 赞助）；2026-10-14 前赞助 $15+ 的用户免费获得 LTX。

**3. 精细控制。** Segment Editor 支持只还原选定区域并带预览；Video Player 支持**实时观看还原效果而不落盘**；VR180 视频的左右眼格式有专门处理；显存不够时调低 Max Clip Size（如 90→60）即可。

**4. 首次运行的"热身税"。** NVIDIA 上首次任务会用 15–60 分钟为你的具体 GPU 准备模型（步骤 2/4 及 UNet 4x 的 TensorRT 编译），仅此一次；升级版本时把 `model_weights` 文件夹拷过去即可免去等待。

## 安装与上手

```bash
# 1. 下载对应系统与 GPU 的 release（路径勿含中文/日文/重音字符）
# 2. Windows: 双击 jasna.exe
#    Linux NVIDIA: 运行 jasna
#    Linux AMD: 运行 run_jasna_amd.sh
# 3. 拖入视频 → 选设置 → 点 ▶
```

首次任务耐心等模型预热；之后每个设置项都有悬浮提示（ⓘ），VRAM  tuning、去噪、60→30 FPS、LUT、锐化、队列后处理动作等进阶选项在文档中均有指南。也支持云 GPU（RunPod、Vast）与源码运行（源码版仅免费 BasicVSR++）。

## 点评

**亮点**是把一条相当复杂的视频修复流水线工程化到了"双击即用"：场景切换自动断片、片段重叠消缝、只动马赛克区域、硬件解码编码全程加速，这些细节都是实际使用中才会发现的痛点。双模型路线（快而免费的 BasicVSR++ / 慢而细的 LTX）给了清晰的选择梯度，LTX 还提供免费试跑模式让用户先验证自己 GPU 跑不跑得动。谱系上也光明正大：灵感与部分模型来自 Codeberg 上的 Lada（`mosaic_restoration_1.2` 模型由 Lada 作者训练），VR 检测模型由 ZeLeFans 提供——开源社区的正常接力。

**局限**要认清：**AGPL-3.0 协议**对商用再分发有传染性要求；最强模型 LTX 与 UNet 4x 是付费墙后的赞助者模型，免费档画质有天花板；首次使用 15–60 分钟的 GPU 模型预热劝退急性子；Windows 路径含非英文字符会直接出问题；扩散路线对显存要求高。另外，此类工具的用途边界需要使用者自行把握——项目本身定位是视频修复工具。

适合人群：视频修复与画质增强爱好者、需要局部区域时序超分的视频处理工作者、VR180 内容创作者、研究视频超分/生成式修复的研究者，以及想本地跑通"检测-跟踪-修复-合成"全链路的 GPU 玩家。
