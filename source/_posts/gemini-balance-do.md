# gemini-balance-do

> Gemini API 中转：多 key 负载均衡，稳定美国 IP

**仓库地址**：https://github.com/zaunist/gemini-balance-do

## 项目简介

Gemini API 中转：多 key 负载均衡，稳定美国 IP。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- 负载均衡
