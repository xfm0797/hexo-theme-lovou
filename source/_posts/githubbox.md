# githubbox

> 在 CodeSandbox 中快速打开 GitHub 仓库

**仓库地址**：https://github.com/dferber90/githubbox

## 项目简介

在 CodeSandbox 中快速打开 GitHub 仓库。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
