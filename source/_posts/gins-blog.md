# Gins-Blog

> 高性能 Agentic-First 博客平台，内置 MCP 协议

**仓库地址**：https://github.com/IchimaruGin728/Gins-Blog

## 项目简介

高性能 Agentic-First 博客平台，内置 MCP 协议。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
