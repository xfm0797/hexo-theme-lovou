# cf-page-publish-mcp

> 将 HTML 页面发布到 CF 的 MCP 工具，可对接 AI

**仓库地址**：https://github.com/Actrue/cf-page-publish-mcp

## 项目简介

将 HTML 页面发布到 CF 的 MCP 工具，可对接 AI。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
