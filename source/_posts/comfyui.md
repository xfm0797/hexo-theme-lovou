## 它想解决什么问题

在 AI 绘画圈，有一条著名的鄙视链：顶端是用 ComfyUI 的"工程师"，中间是用 WebUI 的"玩家"。这个调侃背后，是 ComfyUI 用节点图（node graph）重新定义 AI 创作工作流的结果——它以 14.2 万 Stars 位列 GitHub 全站明星项目前列，是整个扩散模型生态的事实标准入口。

## 节点图：把 AI 创作变成"搭电路"

ComfyUI 的核心交互是节点图：加载模型是一个节点，输入提示词是一个节点，采样器是一个节点，VAE 解码是一个节点——你用线把它们连起来，数据流向即创作流程。这套设计看似"极客"，实则解决了 AI 创作最深层的痛点：

**精确控制。** WebUI 把一切都藏在滑块和选项后面，而 ComfyUI 把每个中间步骤都暴露出来。想做"图生图 + 局部重绘 + 双模型混合 + ControlNet 姿态控制"？就是把对应节点串成一条链，每一步的输入输出都看得见、改得动。

**完全复用。** 工作流可以保存为 JSON 文件，一键导出分享。别人调好的"电商产品图工作流""动漫线稿上色工作流"，导入即用。围绕 ComfyUI 已经形成了庞大的工作流交易与分享生态——这是任何封闭 GUI 都给不了的。

**批量与自动化。** 节点图 + API 后端能力让 ComfyUI 同时是生产流水线：批量出图、接入自动化系统、当推理后端都行。

## 快速上手

```bash
git clone https://github.com/Comfy-Org/ComfyUI
cd ComfyUI && pip install -r requirements.txt
python main.py
```

建议从社区工作流模板入门，先跑通一条完整链路再自己搭节点。

## 点评

**亮点**：节点图这一交互范式让它从工具进化成了平台——工作流即资产、社区即生态、API 即后端；14 万星的虹吸效应使新模型几乎总是第一时间有 ComfyUI 支持；GPL-3.0 之下商业化生态（API 服务、工作流市场）依然繁荣。

**局限**：学习曲线陡峭是公认的门槛，新手第一晚大概率在找节点连线；GPL-3.0 对想闭源集成的团队有约束；节点图在超复杂工作流下的可维护性开始吃力。

适合人群：追求精确控制的 AIGC 创作者、需要批量生产管线的团队、想把扩散模型嵌入自己产品的开发者——只要你在 AIGC 这行，ComfyUI 迟早要学。
