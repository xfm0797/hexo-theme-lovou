# GitPush

> GitHub 项目更新订阅工具：AI 总结 + 邮件通知

## 项目简介

GitHub 项目更新订阅工具：AI 总结 + 邮件通知。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
