# Penpot

> 浏览器里的设计协作平台：基于开放标准、可自托管，设计稿不再锁在别人的云端

## 它想解决什么问题

设计工具的迁移成本极高：文件格式私有、协作在别人云端、团队一换工具等于重做资产。而设计与开发的交接，长期靠截图加标注这种低带宽方式。

Penpot 的两个赌注：**文件用开放格式（SVG 为基础）**，以及**自托管可行**。这让设计资产真正属于团队自己。

## 核心机制拆解

**1. 开放格式。** 设计文件本质是可导出、可解析的结构，与 Web 标准（CSS、SVG）对齐，交接给前端时信息损失小。

**2. 浏览器内协作。** 多人实时编辑、评论、原型交互都在浏览器完成，无需安装客户端。

**3. 设计与代码打通。** 支持查看元素的 CSS/属性，设计稿到实现的映射更直接。

**4. 自托管。** 官方 Docker Compose 部署，团队可把设计文件放在内网。

## 安装与上手

```bash
git clone https://github.com/penpot/penpot.git
cd penpot/docker/compose
docker compose -f docker-compose.yaml up -d
```

打开 `http://localhost:9001` 注册账号即可创建团队与项目。

## 点评

**亮点**是"开放标准"这个选择的长远价值：设计资产不再被单一厂商绑架，自托管解决了合规与数据主权问题，而 SVG 基础让设计到代码的转换更自然。

**局限**：功能深度与插件生态仍不及成熟商业工具，复杂组件系统与自动布局能力在追赶中；Clojure 技术栈让二次开发门槛偏高；自托管部署组件较多（前端、后端、数据库、对象存储、邮件），运维成本不小；大文件与复杂画布的编辑器性能一般。

**适合人群**：有数据主权要求的设计团队；开源项目的 UI 协作；以及想摆脱订阅制设计工具的公司。
