# cf-drop

> 「文件传输助手」：Worker + R2 + D1，PWA 优化、打包下载

**仓库地址**：https://github.com/lyonbot/cf-drop

## 项目简介

「文件传输助手」：Worker + R2 + D1，PWA 优化、打包下载。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
