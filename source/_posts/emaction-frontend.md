# emaction.frontend

> 基于 D1 的 GitHub 风格 Reactions 点赞组件（前端）

**仓库地址**：https://github.com/emaction/emaction.frontend

## 项目简介

基于 D1 的 GitHub 风格 Reactions 点赞组件（前端）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- 点赞
