# ip-check

> Python 实现的 CDN 测速，支持多格式 IP 输入与筛选

**仓库地址**：https://github.com/lovegitgit/ip-check

## 项目简介

Python 实现的 CDN 测速，支持多格式 IP 输入与筛选。该项目在本地运行的命令行工具，用于测速与优选 Cloudflare CDN IP，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
