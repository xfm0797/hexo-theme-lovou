# Cloudflare-WeChat-Notifier

> 微信通知桥接服务（Workers + Hono + D1 + Queues）

**仓库地址**：https://github.com/krapnikkk/Cloudflare-WeChat-Notifier

## 项目简介

微信通知桥接服务（Workers + Hono + D1 + Queues）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- 微信通知
- Hono
- Queues
- D1
