# cf-workers-status-page

> 状态页监控 + Slack 通知（Workers + CRON + KV）

**仓库地址**：https://github.com/eidam/cf-workers-status-page

## 项目简介

状态页监控 + Slack 通知（Workers + CRON + KV）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
