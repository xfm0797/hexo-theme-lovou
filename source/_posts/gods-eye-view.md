## 它想解决什么问题

如果一个网页应用让你觉得自己坐进了好莱坞电影里的"上帝之眼"指挥中心——手指一划就能追踪全球上空的航班、盯着马六甲海峡的每艘货轮、看星链卫星从头顶掠过——你的第一反应大概是：这又是哪个特效 demo？

但 God's Eye View（下称 GEV）的官方介绍非常直白："一个浏览器里的间谍卫星模拟器——直到你发现数据源全是公开的，数据全是真的。"

这正是它要解决的问题：ADS-B 应答机、AIS 船舶信标、卫星轨道根数、地震台网、公共摄像头，这些信号本就存在于互联网上，只是散落在几十个互不相通的网站和 API 里。GEV 把它们汇到同一个可交互的 3D 地球上——**看起来像禁地 cockpit，但每一行代码都可审查、每一个数据源都公开**。

## 核心机制拆解

**1. 二十多个实时数据层，几乎全是公开源。** 这是项目最"吓人"的部分：

- **航班**：OpenSky Network + adsb.lol，11,000+ 架飞机实时位置，军用通道单独标注；
- **船舶**：AISStream 提供的全球船舶 AIS 信标位置；
- **卫星**：CelesTrak TLE 轨道数据，838 个编目天体按轨道类别着色，DENSE 模式直接加载整个星链星座；
- **地震**：USGS 全球地震活动（近 24 小时）；
- **天气**：NOAA GFS / ECMWF 预报风场、雷达回放、卫星云图、雷电密度、气旋路径——无需 API Key；
- **公共摄像头**：来自 12+ 城市/地区 API 的约 3,900 路公开 CCTV，投影在 3D 空间中，机位可校准；
- **电台**：750+ 个地理定位的世界电台，带拟物调台界面；
- **公共交通**：波士顿、奥斯汀、赫尔辛基、荷兰、挪威等地的 GTFS-Realtime 实时数据。

**2. 诚实的精度标注。** 交通流是沿真实道路用聚合位置数据模拟的，摄像头机位与火箭轨迹属于粗估，作者在 README 里逐项标了各类数据的精度。这份坦诚反而更让人觉得项目扎实——它不假装自己是军情系统。

**3. 交互才是让人上头的地方。** 数据只是底座：

- **驾驶舱视角**：钻进一架被追踪的航班内部，相机全程锁定脚下地形；
- **250 公里接触名录**：目标周围的一切尽收眼底，逐台查看并随时切入驾驶舱；
- **点击即追踪**：相机锁定目标、绘制拖尾、展示完整元数据；追踪一艘船时可一键切换到最近的实时摄像头；
- **3D 机库**：真实机型模型（787、ATR-72、Citation、Bell 206、MQ-9），距离拉近后图标自动切换为 3D 模型；
- **传感器滤镜**：CRT、夜视仪、FLIR 热成像、黑色电影、雪地五种 GLSL 视觉特效；
- **语音白板与卫星过境**：对着地球说话，标注边界、路线，也可以直接问"某颗卫星下次什么时候过我头顶"；
- **军事 HUD**：情报风格遥测的战术平视显示。

**4. 语音 Agent 先看场景再回答。** 内置基于 OpenAI Realtime API 的实时智能体（或可选 ChatGPT OAuth 会话），回答前会先拉取当前场景上下文——坐标、街道名、激活图层、视图缩放级别。配一个免费的 Cesium ion Token 可获得谷歌逼真 3D 城市；不加任何 Key 也能启动，默认使用 Esri 卫星影像。密钥只经服务端代理，浏览器拿不到长期凭据。

**5. 无框架模块化。** Vanilla JS + Cesium + Vite，每个数据层是独立模块，可以自行增删——想加一个新数据源，加一个文件即可。

## 安装与上手

零配置启动，三条路径任选：

```bash
# 路径 1：Pinokio 一键安装（Windows/macOS/Linux）

# 路径 2：本地克隆
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci && npm run dev

# 路径 3：Docker（无需 Node）
docker compose up
```

密钥（Cesium ion / Google Maps）在应用内 **POWER UP** 面板按需添加，不入库。

## 点评

**亮点**是"零配置可用"做到了同类罕见的高度：二十多个图层大部分免密钥，Esri 卫星影像开箱即用，语音与 3D 城市作为可选升级而非门槛。语音 Agent 的"先看场景再回答"加上 MCP 集成，让它成为少见的"Agent 可驱动的地理空间界面"。

**局限**要说清楚：其一，**MIT 只覆盖源码**，bundled 的部分数据集（海底电缆、数据中心、洪水影像等）各有 CC BY-NC-SA / ODbL 之类条款，商用前须逐个核对 `DATA_SOURCES.md`；其二，重度依赖第三方 provider 的配额与条款，Google Maps 路线是计费的；其三，它天然带有监控伦理争议——把军用航班、公开摄像头、车牌摄像头位置聚于一屏，作者的对策是透明与可审查（只标位置、不含车牌数据与视频流），项目亦明确定位为 OSINT 与教育目的；其四，部分图层依赖的上游服务会变动，Overpass 之类的接口拒绝旧版本时会直接失效。

**适合人群**：GIS 与 OSINT 从业者、前端可视化工程师、想研究"实时信号 + LLM Agent 如何交互"的工程师，以及单纯想看看"地球今晚在忙什么"的人。

当你能直观看到自己头顶每秒有多少信号在广播，会重新理解数字时代的隐私边界——这大概是这个项目最意外的一堂课。
