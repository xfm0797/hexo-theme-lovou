# Page-api-forwarder

> 绕过 API IP 限制的转发工具

**仓库地址**：https://github.com/xinjianzhanghao/page-api-forwarder

## 项目简介

绕过 API IP 限制的转发工具。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- API 转发
- Pages
- IP 限制
