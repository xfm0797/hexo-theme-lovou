## 它解决什么问题

国内网盘用户都有一个共同的心结：下载个大文件，非要装客户端。客户端体积庞大、弹窗不断、还有说不清道不明的"策略性限速"。LinkSwift 是基于 JavaScript 的油猴脚本，目标只有一个：**在网页端直接获取网盘文件的真实下载地址**，然后交给你喜欢的下载器。从"网盘直链下载助手"一脉改编而来。

## 核心机制

**1. 网页注入辅助面板。** 在网盘页面里解析出文件直链，可以：复制直链交给 IDM、aria2、Motrix、Downie 等任意下载器；批量选中文件、文件夹一次获取全部直链。

**2. 配套扩展脚本。** 同名作者还维护 123 云盘 / 百度网盘会员青春版等扩展脚本，组合使用体验更完整。

**3. 作者立场：克制与合规。** README 里的两份声明值得称道：本项目获取的下载链接均基于各大网盘服务商公开的 API 接口，未以任何形式破解限速机制；若获得较快下载速度，通常系平台策略差异或网络环境所致。这个坦诚的边界划得很专业。

## 安装与上手

安装 Tampermonkey 或脚本猫，从仓库安装脚本，打开任一支持的网盘页面即可看到辅助面板。支持八大量产网盘，具体用法见仓库文档。

## 点评

**亮点**：2.67 万星证明了这是国内网盘用户的真实刚需；对八大盘子的覆盖广度无出其右；作者的合规声明清晰克制——只解析公开 API 不碰破解，这在同类脚本里是负责任的姿态。

**局限**：油猴脚本天然依赖网盘前端结构，改版即失效需跟进更新；AGPL-3.0 与网盘服务条款的灰色地带需自行判断；直链下载的稳定性取决于各平台策略。

适合人群：同时混用多个网盘、不想装一堆客户端的重度用户——装一个脚本，桌面清爽一半。
