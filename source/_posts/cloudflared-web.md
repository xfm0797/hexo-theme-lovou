# Cloudflared-web

> 打包 cloudflared CLI 与 Web UI 的 Docker 镜像

**仓库地址**：https://github.com/WisdomSky/Cloudflared-web

## 项目简介

打包 cloudflared CLI 与 Web UI 的 Docker 镜像。该项目以 Docker 镜像方式分发运行，可配合 Cloudflare Tunnel 使用，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- Docker
