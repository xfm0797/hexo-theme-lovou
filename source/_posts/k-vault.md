# K-Vault

> 以 Telegram 为核心的聚合云盘，兼容 R2 / S3 / Discord / HuggingFace

**仓库地址**：https://github.com/katelya77/K-Vault

## 项目简介

以 Telegram 为核心的聚合云盘，兼容 R2 / S3 / Discord / HuggingFace。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- Telegram
- R2
- S3
