# Langflow

> 拖拽式构建 AI 应用：节点连线就是数据流，画完直接当 API 跑，也能导出成代码

## 它想解决什么问题

AI 应用的原型阶段最痛苦的是"改一次试一次"：调提示词、换模型、加一步检索，每改一处都要重跑脚本、重看日志。

Langflow 把流程变成画布：节点是组件，连线是数据流，改哪一步就改哪个节点，结果即时可见。

## 核心机制拆解

**1. 节点即组件。** 模型、提示词、检索器、工具、条件分支都是节点，输入输出在连线上流动，结构一目了然。

**2. 即时试跑。** 画布里可以直接看每个节点的中间结果，调试提示词时不必猜是哪一步出了问题。

**3. 一键成 API。** 画好的流程可发布为接口，前端或其他服务直接调用；也能导出代码自己接管。

**4. 可嵌入。** 支持把流程嵌进自己的应用，或作为 MCP/工具供 Agent 调用。

## 安装与上手

```bash
pip install langflow
langflow run
```

打开 `http://localhost:7860`，从模板起步（RAG、聊天、Agent 都有），改节点比从空白画布搭快得多。

## 点评

**亮点**是调试体验：把中间结果可视化这件事，对提示词工程效率的提升远超预期。加上能导出代码，它不像某些低代码平台那样把逻辑锁死在自己的运行时里。

**局限**：画布适合线性与浅分支，复杂控制流会迅速变成"面条图"；节点生态虽多但质量不一，冷门集成容易踩坑；版本升级较快，旧流程偶有兼容问题；生产部署仍需自己考虑鉴权、并发与限流，它本身不是网关。

**适合人群**：想快速验证 AI 产品想法的产品与研发；需要给业务同学演示流程的技术团队；以及把 LangChain 组件当积木用的开发者。
