## 它想解决什么问题

做一条知识类短视频，流程是：想选题、写脚本、找素材、配音、配字幕、剪辑。单条不难，难在规模化——每天三条，人工成本立刻压不住。

这个项目把整条流水线串起来：**给一个主题，剩下的步骤自动跑完**，输出可直接发布的竖版视频。

## 核心机制拆解

**1. 一条命令串全流程。** 大模型写文案与分镜，素材库按关键词取画面，TTS 配音，自动生成字幕并对齐，最后用 FFmpeg 合成。

**2. 多模型可选。** 文案生成可接国内外多家大模型，也能用本地模型；语音合成同样多provider，音色与语言可切换。

**3. 素材来源灵活。** 内置免版权素材源，也可替换为本地素材目录，避免撞图。

**4. Web 界面。** 浏览器里填主题、调参数、看预览，不用记命令行参数。

## 安装与上手

```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
docker compose up
```

打开 Web 界面，填入模型 Key，输入主题即可生成。

## 点评

**亮点**是把"全流程"做通了：市面上多数工具只解决其中一环（比如只做配音或只做字幕），而它交付的是可发布的成品。对做矩阵号、批量内容的团队，这个差别就是产能。

**局限**：成片质量取决于素材匹配与文案质量，"看起来像模板"的问题普遍存在；素材版权需要自己确认，商用前务必逐项核实；TTS 与字幕对齐在长句、专业术语上仍会出错；生成速度受下载素材与合成影响，批量跑要排队。

**适合人群**：做知识类、资讯类短视频的批量内容团队；想快速验证选题的创作者；以及研究"AI 内容流水线"的开发者。
