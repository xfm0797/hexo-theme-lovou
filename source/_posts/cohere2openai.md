# cohere2openai

> Cohere API 转 OpenAI 兼容 API

**仓库地址**：https://github.com/beanqi/cohere2openai

## 项目简介

Cohere API 转 OpenAI 兼容 API。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- Cohere
- OpenAI 兼容
