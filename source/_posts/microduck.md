## 它想解决什么问题

在满屏 Agent / Skill / 插件项目里，Trending 日榜上突然出现一只鸭子——这本身就是个信号：embodied AI 的另一半在硬件里。

过去，波士顿动力的机器人是黑盒，MIT Mini Cheetah 是研究级。Microduck 把开源机器人的体验压缩到了 800 克、几千美元和一条 `git clone`。

## 核心机制拆解

**1. 一只鸭子能干什么。** README 用四个视频说话：走（接游戏手柄就能开）、滚（装轮子切到 roller 模式，加载另一套"大脑"）、捡东西（嘴贴地，一个按钮）、摔倒了站起来。此外还会坐、踢球、听令向前滚，以及"用一种只属于它自己的声音嘎嘎叫"。

**2. 教科书式的 RL 机器人栈。** 策略在隔壁仓库 `microduck_rl` 里训练：**MuJoCo + PPO + domain randomisation**，导出 ONNX，本仓库加载执行。RK3566 这种电视盒芯片跑 50Hz 环路，说明端侧 RL 推理的硬件门槛已经低到荒谬。

**3. 更新机制做成了产品级。** 每次更新都经过验证、健康门控、可回滚——"把新软件装到机器人上而不把它变砖"这件事，被认真对待。这类细节最能区分"玩具项目"与"可维护项目"。

**4. 开发者友好到离谱。**

- 没有真鸭子也能开发：`scripts/duck-sim` 让真实守护进程跑在 MuJoCo 仿真身体上，窗口里看一只，或开四只当四台机器登录；
- `duckctl`：从笔记本通过蓝牙直接控制机器人，不需要网络和 ssh；
- 一分钟上分支：本机构建 → ssh 安装，官方口径约一分钟；
- 从一块空白板到能跑分支构建的开发板，文档一步步铺好。

## 点评

**亮点**是 sim2real 全链路公开：仿真器、真机、训练代码、部署工具链四件套全齐，Rust 固件质量也对得起 Apache-2.0。对想入门强化学习机器人的人来说，这是目前最容易上手的"活的"平台之一。

**局限**：硬件需要单独购买，纯软件玩家只能玩仿真；15 个舵机的机械结构有磨损与标定成本，长期可靠性取决于维护；"几千美元"对个人仍是笔投入，教育 / 实验室场景更合适。

适合人群：机器人 / RL 学习者（sim2real 的最佳入门载体之一）；硬件创客（开源固件 + 可购买硬件，改什么都有文档）；想要一台会走会叫的桌面摆件的人。
