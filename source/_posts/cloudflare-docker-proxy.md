# cloudflare-docker-proxy

> 运行在 Worker 上的 Docker Hub 注册代理

**仓库地址**：https://github.com/ciiiii/cloudflare-docker-proxy

## 项目简介

运行在 Worker 上的 Docker Hub 注册代理。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- Docker 加速
- Workers
- 镜像代理
