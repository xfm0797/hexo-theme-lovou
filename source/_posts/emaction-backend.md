# emaction.backend

> 基于 Workers + D1 的 Reactions 点赞服务（后端）

**仓库地址**：https://github.com/emaction/emaction.backend

## 项目简介

基于 Workers + D1 的 Reactions 点赞服务（后端）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- Reactions
- Workers
- D1
