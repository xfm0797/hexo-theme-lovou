# Octop

> 完全自托管、多用户、多智能体的 AI 助手平台：`octop run` 一条命令拉起全部，数据不出家门

> **项目速览**

> | --- | --- |
> | 仓库 | [TencentCloud/Octop](https://github.com/TencentCloud/Octop) |

> | Stars / Forks | 10,500+ / 1,300+（截至 2026-10-21） |
> | 协议 | MIT |
> | 安装 | `pip install octop`，一条 `octop run` 启动全部 |

## 它想解决什么问题

"AI 助手"的开源项目不少，但多数是单用户的"个人玩具"——想让全家共用、团队协作、数据还不出家门，选择突然稀缺。腾讯云 2026 年 7 月开源的 Octop 瞄准的正是这块空白：一个完全自托管、多用户、多智能体的 AI 助手平台。它把自己描述为"一种可以并行运作的数字生命形态"——通过多智能体架构，为团队、家庭和个人构建既独立又协作的智能环境。开源三个月已破 10,500 Stars。

## 核心机制拆解

**1. 单进程启动，部署复杂度刻意压低。** Web 控制台、CLI、IM 渠道（飞书、钉钉、QQ、微信、Telegram、Discord、企业微信）、定时任务全部由 `octop run` 一个命令拉起，共享 `~/.octop/` 下的控制面数据库（默认 SQLite，可选 PostgreSQL）。没有微服务全家桶。

**2. 多用户专家团队。** 一个管理员 + 家庭共享模式，内置"专家库"与"专家市场"，按场景切换不同专长的智能体；AgentTeams（Beta）让协调者调度多个专家完成多步工作。

**3. 个性与记忆。** 16 套 MBTI 人格模板 + 互动测试，给每个 Agent 独特的性格；长期记忆让 Agent 记得你的偏好。

**4. 隐私不让步。** 每一段对话、每一个工作区、每一个凭证都留在你自己的机器上——设计目标写得直白。

## 安装与上手

```bash
pip install octop
octop run
```

启动后按控制台引导配置模型 API 与用户，IM 渠道按需接入。

## 点评

**亮点**：把"多用户 + 自托管 + 多 Agent"三个需求打包在一起的产品在国内开源里罕见；单进程启动对家庭/小团队部署极友好；IM 渠道覆盖之全（连企业微信都有）是面向中国用户生态的诚意之作；MIT 协议干净。

**局限**：Python 单进程架构在用户规模大时的并发上限需评估；智能体能力深度依赖所接模型；AgentTeams 还在 Beta；与腾讯云生态的边界需留意。

适合人群：想给家庭/小团队搭私有 AI 助手的玩家、需要多 Agent 协作又要数据自持的团队、关注国产开源 Agent 平台生态的开发者。
