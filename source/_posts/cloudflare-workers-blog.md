# cloudflare-workers-blog

> 以 KV 作数据库的 Workers 博客，兼具静态速度与动态灵活

**仓库地址**：https://github.com/gdtool/cloudflare-workers-blog

## 项目简介

以 KV 作数据库的 Workers 博客，兼具静态速度与动态灵活。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
