# UptimeFlare

> 无服务器站点监控：支持 HTTP / HTTPS / TCP，全球数百城市探测

**仓库地址**：https://github.com/lyc8503/UptimeFlare

## 项目简介

无服务器站点监控：支持 HTTP / HTTPS / TCP，全球数百城市探测。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- 全球探测
