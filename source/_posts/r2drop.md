# R2Drop

> 原生 macOS 菜单栏 R2 上传应用（Swift + Rust）

**仓库地址**：https://github.com/superhumancorp/r2drop

## 项目简介

原生 macOS 菜单栏 R2 上传应用（Swift + Rust）。该项目以原生 macOS 应用的形式运行，对接 Cloudflare R2 存储，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- R2
- macOS
- Swift
