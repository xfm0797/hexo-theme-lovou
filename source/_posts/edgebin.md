# Edgebin

> 类似 httpbin 的 HTTP 测试服务

**仓库地址**：https://github.com/jiacai2050/edgebin

## 项目简介

类似 httpbin 的 HTTP 测试服务。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- HTTP 测试
- httpbin
- Workers
