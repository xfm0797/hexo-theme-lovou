# redirect-checker

> HTTP 重定向链分析器，RESTful API + Web UI

**仓库地址**：https://github.com/brancogao/redirect-checker

## 项目简介

HTTP 重定向链分析器，RESTful API + Web UI。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
