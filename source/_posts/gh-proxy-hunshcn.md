# gh-proxy（hunshcn 版）

> GitHub release、archive、clone 加速代理（Workers 版 + Python 版）

**仓库地址**：https://github.com/hunshcn/gh-proxy

## 项目简介

GitHub release、archive、clone 加速代理（Workers 版 + Python 版）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- GitHub 加速
- Workers
- Python
