# Godot

> 完全免费、MIT 协议、无分成无抽成：从 2D 到 3D，引擎源码与你的游戏都属于你自己

## 它想解决什么问题

独立开发者用商业引擎最难受的不是功能，而是**条款**：收入到线要分成、引擎闭源无法排查底层问题、插件与工具链受平台方政策左右。

Godot 的立场极简：MIT 协议，引擎可改可分发，做出来的游戏 100% 属于你，没有版税。

## 核心机制拆解

**1. 场景与节点。** 一切皆节点，场景是节点树，可以嵌套复用。这套模型对 2D 特别顺手，2D 与 3D 是两套独立管线而非"3D 降维"。

**2. GDScript。** 类 Python 的脚本语言，与引擎深度绑定，改一行就能在编辑器里看到效果，迭代快。

**3. 编辑器轻量。** 安装包几十 MB，启动迅速，可在低配机器与 Linux 上顺畅工作——这对独立开发者很实际。

**4. 导出与扩展。** 一键导出到多平台；需要性能时可用 GDExtension 写 C++/Rust 模块。

## 安装与上手

从官网下载编辑器，新建项目选 2D 模板；或：

```bash
git clone https://github.com/godotengine/godot.git
cd godot && scons platform=linuxbsd target=editor
```

第一个项目建议做"移动角色 + 碰撞 + 收集物"，把场景与信号机制跑通。

## 点评

**亮点**是"没有隐藏成本"：MIT 协议 + 无版税 + 源码可读，让它在教育与独立开发圈形成了稳定生态。轻量编辑器让"随手打开做两小时"成为可能，这对个人项目是决定性因素。

**局限**：3D 能力与主流商业引擎仍有差距，大型 3D 项目要慎重；插件与素材市场生态较小，很多轮子要自己造；主机平台导出需要第三方方案，流程不如商业引擎顺；GDScript 性能有限，重计算逻辑需换语言；团队协作工具链（版本管理、资源冲突）仍偏手工。

**适合人群**：2D 独立游戏开发者；教学与游戏开发入门；以及要求"代码与产物完全自主"的团队。
