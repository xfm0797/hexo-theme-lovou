# imgUU

> 基于 D1 + R2 的免费图片上传应用，支持 GitHub 登录管理

**仓库地址**：https://github.com/yestool/imgUU

## 项目简介

基于 D1 + R2 的免费图片上传应用，支持 GitHub 登录管理。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
