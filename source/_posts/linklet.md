# linklet

> 以 API 模式实现的 URL 缩短器，适用场景更多

**仓库地址**：https://github.com/harrisonwang/linklet

## 项目简介

以 API 模式实现的 URL 缩短器，适用场景更多。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
