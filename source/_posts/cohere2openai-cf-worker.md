# cohere2openai-cf-worker

> Cohere API 转 OpenAI 兼容 API（Workers 版）

**仓库地址**：https://github.com/ckt1031/cohere2openai-cf-worker

## 项目简介

Cohere API 转 OpenAI 兼容 API（Workers 版）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。
