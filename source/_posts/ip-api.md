# ip-api

> 快速搭建 IP 地址与地理位置查询接口

**仓库地址**：https://github.com/ccbikai/ip-api

## 项目简介

快速搭建 IP 地址与地理位置查询接口。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

## 关键技术

- IP 查询
- Workers
- 地理位置
