# cf-vps-monitor

> Workers 上的 VPS 监控 + 网站监测面板（D1 存储）

**仓库地址**：https://github.com/kadidalax/cf-vps-monitor

## 项目简介

Workers 上的 VPS 监控 + 网站监测面板（D1 存储）。该项目运行在 Cloudflare Workers 边缘运行时上，依托全球边缘网络分发，个人使用者基于 Cloudflare 免费套餐即可自部署运行。

- VPS 监控
- D1
- 面板
