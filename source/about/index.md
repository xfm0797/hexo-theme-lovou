## 关于「墨痕」

「墨痕」是一个基于 [Hexo](https://hexo.io/) 的极简现代风中文博客主题，也是我开源的第一个项目。

设计哲学很简单：

- **极简，但不冷淡** — 去掉多余的装饰，保留阅读的本质
- **现代，但不喧哗** — 用当代的设计语言，不过度追求视觉刺激
- **中文优先** — 从字体栈到排版细节，为中文阅读体验精心调校

如果你也喜欢这个主题，欢迎去 [GitHub](https://github.com/xfm0797/hexo-theme-lovou) 点个 Star，你的认可是我最高的动力。

## 开源项目

### [hexo-theme-lovou](https://github.com/xfm0797/hexo-theme-lovou)

> 一个极简现代风、专为中文博客设计的 Hexo 主题。

就是你正在看的这个主题。基于 CSS 构建，轻量、快速、易于定制。

### [x-site](https://github.com/xfm0797/x-site)

> 跨平台静态博客桌面客户端，类 Gridea 体验。

基于 Tauri v2 + Vue 3 + TypeScript + Rust 构建，安装包小于 15MB，启动快、内存占用低。让你像写日记一样写博客。

### [X-admin](https://github.com/xfm0797/X-admin)

> 基于 PHP + SQLite3 的轻量级动静分离内容管理系统。

核心设计理念是动静分离：后台使用 PHP 动态管理内容，前端由 Nginx/Apache 直接输出静态 HTML，完全不经过 PHP，兼顾管理便捷与访问性能。开源、免费、可自由修改分发。

### [xfm-cms](https://github.com/xfm0797/xfm-cms)

> 小微企业产品展示型官网程序。

基于 PHP 7.4 + SQLite3/MySQL 多数据库支持，一套轻量级的小微企业官网解决方案。版本 v1.0.0，适合需要快速搭建产品展示网站的用户。
